# Köderkönige

2D-Wettkampf-Angel- und Sammelspiel im Browser: 2–4 Freunde, 100 Fische, 5 Welten, detaillierte Pixel-Art.

- Spezifikation: [`GAME_SPEC.md`](GAME_SPEC.md)
- Dauerregeln und Befehle: [`CLAUDE.md`](CLAUDE.md)
- Entscheidungen: [`docs/entscheidungen.md`](docs/entscheidungen.md) · Platzhalter: [`docs/platzhalter.md`](docs/platzhalter.md)
- Hosting einrichten: [`docs/hosting.md`](docs/hosting.md)

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # Logik-, Daten- und Asset-Tests
npm run test:e2e   # Browser-Tests (Desktop, iPhone, Android)
```
